# IRON MAN — AI·반도체 주요 기사 알림 앱

해외 AI·반도체 뉴스 중 지금 가장 주목받는 기사 5건을 골라 보여주고, 매일 오전 8시·오후 8시(한국시간)에 휴대폰 알림으로 보내주는 **개인용 웹앱**이에요.
비전문가도 읽기 쉽게 기사마다 한국어 제목, 핵심 3줄 요약, 새 기술의 쉬운 설명을 붙여 줘요.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 주요 기사 5건 | 구글 뉴스 RSS에서 AI 기사 3건 + 반도체 기사 2건을 골라 보여줘요 (10분마다 새로 받아옴) |
| 하루 2번 알림 | GitHub Actions가 매일 08:00·20:00에 새 기사 최대 5건을 웹 푸시로 보내요. 이미 보낸 기사는 90일 동안 다시 보내지 않아요 |
| 한국어 3줄 요약 | OpenAI(웹 검색)로 기사 내용을 확인해 한국어 제목, 3줄 요약, 쉬운 설명을 만들고, 한 번 만든 요약은 저장해 다시 써요 |
| 요약 AI 모델 고르기 | GPT-5.5(정확함) / GPT-5.4 mini(빠름·저렴) 중에서 골라요 (PIN 필요) |
| 오늘의 주요 영상 | 해외 뉴스 채널 유튜브에서 최근 2일 AI·반도체 영상 중 조회수 1위를 재생해요 (한국어 → 영어 자막 자동 켜기) |
| 지난 기사 | 최근 90일 동안 알림으로 보낸 기사를 최신순으로 보여줘요 |
| 홈 화면에 추가 | 휴대폰 홈 화면에 앱처럼 추가할 수 있어요 (아이폰은 추가해야 알림을 받아요) |

## 기술 스택

- **Next.js 16** (App Router, TypeScript, Tailwind CSS) — 화면과 서버 기능
- **Vercel** — 배포
- **web-push** — 휴대폰·브라우저 알림
- **OpenAI API** — 한국어 요약
- **GitHub Actions** — 하루 2번 알림 발송
- **비공개 GitHub 저장소의 `data/` 파일** — 데이터베이스 대신 보낸 기사·요약·알림 기기 정보를 저장 (GitHub API)

## 구조

```
app/        화면 (메인, 기사 화면, 지난 기사) + 서버 동작(actions.ts)
lib/        기사 가져오기·고르기, 저장소 읽기·쓰기, 알림 보내기, 요약
scripts/    하루 2번 알림을 보내는 스크립트 (npm run notify)
public/     아이콘, 알림을 받는 서비스 워커(sw.js)
```

## 직접 실행하기

```bash
npm install
npm run dev
```

`.env` 파일에 아래 값이 필요해요 (값은 절대 GitHub에 올리지 않아요).

| 이름 | 용도 |
|---|---|
| `GITHUB_TOKEN`, `GITHUB_REPO` | 데이터(`data/`)를 저장할 비공개 저장소와 그 저장소 전용 토큰 |
| `NEXT_PUBLIC_VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` | 웹 푸시 알림 키 |
| `OPENAI_API_KEY` | 한국어 요약 (없으면 요약 없이 동작) |
| `SUBSCRIBE_PIN` | 알림 켜기·끄기와 요약 모델 바꾸기에 필요한 PIN |

## 보안

- 회원가입 없는 1인용 앱이라, 설정을 바꾸는 동작은 모두 PIN으로 보호해요 (여러 번 틀리면 10분 잠금).
- 비밀 키는 서버에서만 쓰고, 화면에는 AI가 만든 글도 글자로만 보여줘요 (링크·주소 제거).
- 허락한 곳의 스크립트만 실행되게 보안 헤더(CSP, HSTS 등)를 붙였어요.
- 알림 기기 정보가 들어 있는 데이터 저장소는 비공개로 따로 두고, 이 공개 저장소에는 코드만 올려요.
